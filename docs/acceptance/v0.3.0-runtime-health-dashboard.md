## Software contract accepted

- The health task is not started by `app_main()`.
- `POST /api/health/control` accepts only a single boolean `enabled` member.
- `GET /api/health` returns explicit off and starting states, refreshes the client lease while enabled, and preserves all ready-snapshot fields.
- The monitor task samples every second, wakes immediately for explicit stop, and exits itself rather than being deleted by its caller.
- A 10-second lapse in health GET requests causes the same safe exit path.
- The inference pipeline remains active regardless of monitor state.
- Browser history is volatile, sequence-deduplicated, and bounded to 60 samples.
- The disabled dashboard copy is `健康任务未开启，网页不请求健康数据，不占用监控任务栈。`
