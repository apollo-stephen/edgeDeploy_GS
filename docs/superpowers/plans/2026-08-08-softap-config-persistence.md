# SoftAP Configuration Persistence Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make fresh ESP32-S3 builds consistently broadcast the project SoftAP as `ESP32S3-CAPTURE` after `set-target` or config regeneration.

**Architecture:** Keep the reusable WIFIAP component and its Kconfig defaults unchanged. Store board/project policy in `sdkconfig.defaults`, verify those exact values with a repository test, and document the effective defaults. Regenerate the ignored `sdkconfig` before rebuilding so the current firmware also uses the persisted values.

**Tech Stack:** ESP-IDF 5.5.4, Kconfig defaults, Python `unittest`, Ninja/ESP32-S3 toolchain

## Global Constraints

- The SSID is `ESP32S3-CAPTURE`.
- Restore the prior project password without logging it at runtime.
- The Wi-Fi channel is 1.
- The maximum station count is 1.
- Do not modify or stage the user's `.gitignore` change.
- Keep the generated `sdkconfig` ignored and keep `components/WIFIAP/Kconfig` generic.

**Files:**
- Modify: `tests/test_wifi_ap_component.py`

- Regenerate (ignored): `sdkconfig`

**Interfaces:**
- Consumes: ESP-IDF project defaults loaded by `idf.py set-target esp32s3` and `idf.py reconfigure`.
- Produces: effective macros `CONFIG_ESP_WIFI_SSID`, `CONFIG_ESP_WIFI_PASSWORD`, `CONFIG_ESP_WIFI_CHANNEL`, and `CONFIG_ESP_MAX_STA_CONN` consumed by `components/WIFIAP/wifi_ap.c`.

- [ ] **Step 1: Write the failing defaults regression test**

Add this method to `WifiApComponentStructureTest` in `tests/test_wifi_ap_component.py`:

```python
def test_project_defaults_preserve_softap_identity(self):
    defaults = read("sdkconfig.defaults")
    self.assertIn('CONFIG_ESP_WIFI_SSID="ESP32S3-CAPTURE"', defaults)
    self.assertIn('CONFIG_ESP_WIFI_PASSWORD="12345678"', defaults)
    self.assertIn("CONFIG_ESP_WIFI_CHANNEL=1", defaults)
    self.assertIn("CONFIG_ESP_MAX_STA_CONN=1", defaults)
```

- [ ] **Step 3: Add the minimal persistent defaults**
